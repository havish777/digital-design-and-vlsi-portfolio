A collection of hands-on projects in RTL design, processor architecture, serial communication, and memory systems. The repository includes Verilog/SystemVerilog source code, testbenches, simulation logs, waveform evidence, and project-specific documentation.

## Projects

| # | Project | Focus | Folder |
|---|---|---|---|
| 1 | **5-Stage Pipelined RISC Processor (MIPS-style)** | Datapath, pipelining, control logic, forwarding, and load-use hazard detection | [01-mips-pipelined-processor](./01-mips-pipelined-processor) |
| 2 | **UART Transmitter and Receiver** | FSM-based TX/RX, baud-rate generation, serial framing, and loopback verification | [02-uart-design](./02-uart-design) |
| 3 | **VIPT Cache (4 KB, 4-way, LRU)** | Virtual indexing, physical tagging, cache pipeline, SRAM modelling, and replacement policy | [03-vipt-cache](./03-vipt-cache) |

## Technical Skills

- **HDL:** Verilog, SystemVerilog
- **Digital design:** Combinational and sequential logic, finite-state machines, counters, shift registers, datapath/control design
- **Computer architecture:** Processor pipelining, forwarding, hazard detection, cache organisation, memory hierarchy
- **Verification:** Testbench development, self-checking tests, simulation-log analysis, waveform generation and debugging
- **Tools:** AMD/Xilinx Vivado, Icarus Verilog, EDA Playground, Python, Bash, Git, GitHub

## Areas of Interest

- RTL design and functional verification
- Processor microarchitecture and RISC-V
- SoC design and integration
- Cache and memory subsystems
- Digital IC and VLSI design

## Repository Structure

Each project directory contains its RTL source, testbench, simulation scripts/logs, documentation, and available waveform evidence. Refer to the README inside each project folder for architecture details, test coverage, results, limitations, and instructions to run the simulation.
